# Lab 01 - Full Stack Development

## Purpose
This repository contains the deliverables for Lab Task 1 of the Full Stack Development course.
It demonstrates basic semantic HTML5, custom CSS styling, and the use of the Bootstrap framework
(grid system, navbar, buttons, and cards), extended into a simple one-page personal portfolio.

## Files
- `index.html` - A personal page built with semantic HTML5 elements, styled using `style.css`.
- `style.css` - Custom CSS styling linked to `index.html`.
- `bootstrap-demo.html` - A one-page personal portfolio built with Bootstrap, including a navbar,
  an "About Me" section (grid system), a "Skills" section (cards), and a "Contact" section
  (button linking to email).

## How to Run
1. Clone or download this repository.
2. Open `index.html` in any web browser to view the semantic HTML page.
3. Open `bootstrap-demo.html` in any web browser to view the Bootstrap portfolio page.
   (Both files use CDN links for Bootstrap, so an internet connection is needed for full styling.)
